# Changelog – Auth Service

## Auth 2.12.2 – 2026-09-24

- Added: per-region metrics for session operations.
- Changed: MFA enrolment validation errors now return a machine-readable `code` field.

## Auth 2.11.0 – 2026-08-15

- Added: an `updated_since` filter when listing API keys.
- Changed: Session writes are now retried once on a transient database error.
- Fixed: incorrect counts after a MFA enrolment was restored.

## Auth 2.10.1 – 2026-07-26

- Added: a dry-run mode for session imports.
- Fixed: time zone handling so session timestamps are always UTC.

## Auth 2.9.0 – 2026-06-20

- Added: an audit entry whenever a session is deleted.
- Fixed: retries creating a second MFA enrolment after a gateway timeout.
- Fixed: retries creating a second session after a gateway timeout.

## Auth 2.8.0 – 2026-05-20

- Added: an audit entry whenever a MFA enrolment is deleted.
- Fixed: a server error when listing API keys for an account that has none.
- Fixed: incorrect counts after a session was restored.

## Auth 2.7.3 – 2026-04-10

- Fixed: session listings returning duplicates across pages.
