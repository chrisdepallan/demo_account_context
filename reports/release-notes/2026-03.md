# Release Notes 2026-03

## Summary

In **2026-03**, **12 services** shipped **39 changes**: **14 additions**, **8 improvements** and **17 fixes**. Each service's full history is in its `CHANGELOG.md`.

## New in 2026-03

- **Accounts** – Added bulk member invitation export to the API.
- **Auth** – Added bulk SSO connection export to the API.
- **Auth** – Added pagination cursors to session listings.
- **Billing** – Added an `updated_since` filter when listing invoices.
- **Support** – Added an audit entry whenever a SLA timer is deleted.
- **Projects** – Added an audit entry whenever a board is deleted.
- **Files** – Added pagination cursors to sharing link listings.
- **Files** – Added per-region metrics for file operations.
- **Notifications** – Added an `updated_since` filter when listing digests.
- **Webhooks** – Added an audit entry whenever a event is deleted.
- **Search** – Added per-region metrics for query operations.
- **Search** – Added per-region metrics for filter operations.
- **Search** – Added pagination cursors to index listings.
- **Audit Log** – Added bulk retention policy export to the API.

## Improved in 2026-03

- **Billing** – Moved refund clean-up to an off-peak window in each region.
- **Files** – Structured logs for upload operations now include the account ID and region.
- **Search** – Reduced p95 latency of saved search lookups.
- **Audit Log** – Audit entry validation errors now return a machine-readable `code` field.
- **Audit Log** – Retention policy writes are now retried once on a transient database error.
- **Integrations** – Moved OAuth grant clean-up to an off-peak window in each region.
- **Analytics** – Moved dashboard clean-up to an off-peak window in each region.
- **Analytics** – Structured logs for dashboard operations now include the account ID and region.

## Fixed in 2026-03

- **Accounts** – Fixed time zone handling so plan change timestamps are always UTC.
- **Accounts** – Fixed a server error when listing accounts for an account that has none.
- **Accounts** – Fixed retries creating a second member invitation after a gateway timeout.
- **Auth** – Fixed a race when two requests updated the same session.
- **Billing** – Fixed invoice listings returning duplicates across pages.
- **Support** – Fixed time zone handling so SLA timer timestamps are always UTC.
- **Projects** – Fixed a server error when listing boards for an account that has none.
- **Projects** – Fixed retries creating a second project after a gateway timeout.
- **Files** – Fixed file version listings returning duplicates across pages.
- **Notifications** – Fixed time zone handling so email template timestamps are always UTC.
- **Notifications** – Fixed a server error when listing notifications for an account that has none.
- **Notifications** – Fixed time zone handling so notification timestamps are always UTC.
- **Webhooks** – Fixed incorrect counts after a event was restored.
- **Audit Log** – Fixed incorrect counts after a export was restored.
- **Integrations** – Fixed a server error when listing integrations for an account that has none.
- **Integrations** – Fixed integration listings returning duplicates across pages.
- **Integrations** – Fixed incorrect counts after a install was restored.
