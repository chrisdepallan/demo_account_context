# Release Notes 2026-05

## Summary

In **2026-05**, **12 services** shipped **39 changes**: **10 additions**, **12 improvements** and **17 fixes**. Each service's full history is in its `CHANGELOG.md`.

## New in 2026-05

- **Accounts** – Added a dry-run mode for plan change imports.
- **Auth** – Added an audit entry whenever a MFA enrolment is deleted.
- **Support** – Added pagination cursors to SLA timer listings.
- **Projects** – Added pagination cursors to task listings.
- **Files** – Added an `updated_since` filter when listing files.
- **Files** – Added an audit entry whenever a upload is deleted.
- **Notifications** – Added an `updated_since` filter when listing notifications.
- **Integrations** – Added an `updated_since` filter when listing installs.
- **Analytics** – Added bulk dashboard export to the API.
- **Analytics** – Added bulk metric export to the API.

## Improved in 2026-05

- **Accounts** – Reduced p95 latency of workspace lookups.
- **Billing** – Reduced p95 latency of credit lookups.
- **Support** – Reduced p95 latency of SLA timer lookups.
- **Projects** – Project validation errors now return a machine-readable `code` field.
- **Notifications** – Notification validation errors now return a machine-readable `code` field.
- **Notifications** – Reduced p95 latency of preference lookups.
- **Webhooks** – Moved webhook endpoint clean-up to an off-peak window in each region.
- **Search** – Reduced p95 latency of index lookups.
- **Audit Log** – Export validation errors now return a machine-readable `code` field.
- **Audit Log** – Reduced p95 latency of retention policy lookups.
- **Analytics** – Moved scheduled export clean-up to an off-peak window in each region.
- **Analytics** – Metric writes are now retried once on a transient database error.

## Fixed in 2026-05

- **Auth** – Fixed a server error when listing API keys for an account that has none.
- **Auth** – Fixed incorrect counts after a session was restored.
- **Billing** – Fixed incorrect counts after a invoice was restored.
- **Billing** – Fixed incorrect counts after a refund was restored.
- **Support** – Fixed SLA timer listings returning duplicates across pages.
- **Projects** – Fixed board listings returning duplicates across pages.
- **Projects** – Fixed project listings returning duplicates across pages.
- **Files** – Fixed a server error when listing file versions for an account that has none.
- **Notifications** – Fixed a server error when listing digests for an account that has none.
- **Webhooks** – Fixed incorrect counts after a signing secret was restored.
- **Webhooks** – Fixed time zone handling so webhook endpoint timestamps are always UTC.
- **Webhooks** – Fixed time zone handling so delivery timestamps are always UTC.
- **Search** – Fixed incorrect counts after a saved search was restored.
- **Search** – Fixed a race when two requests updated the same index.
- **Search** – Fixed index listings returning duplicates across pages.
- **Audit Log** – Fixed audit entry listings returning duplicates across pages.
- **Integrations** – Fixed incorrect counts after a sync job was restored.
