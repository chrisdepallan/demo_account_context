# Release Notes 2026-06

## Summary

In **2026-06**, **12 services** shipped **36 changes**: **10 additions**, **14 improvements** and **12 fixes**. Each service's full history is in its `CHANGELOG.md`.

## New in 2026-06

- **Auth** – Added an audit entry whenever a session is deleted.
- **Projects** – Added an `updated_since` filter when listing boards.
- **Projects** – Added an `updated_since` filter when listing tasks.
- **Files** – Added pagination cursors to upload listings.
- **Files** – Added an `updated_since` filter when listing uploads.
- **Files** – Added pagination cursors to file version listings.
- **Notifications** – Added a dry-run mode for preference imports.
- **Webhooks** – Added an `updated_since` filter when listing deliveries.
- **Integrations** – Added bulk sync job export to the API.
- **Analytics** – Added bulk report export to the API.

## Improved in 2026-06

- **Accounts** – Member invitation writes are now retried once on a transient database error.
- **Accounts** – Reduced p95 latency of member invitation lookups.
- **Billing** – Moved credit clean-up to an off-peak window in each region.
- **Support** – Moved ticket clean-up to an off-peak window in each region.
- **Projects** – Reduced p95 latency of project lookups.
- **Projects** – Task writes are now retried once on a transient database error.
- **Notifications** – Digest validation errors now return a machine-readable `code` field.
- **Notifications** – Structured logs for email template operations now include the account ID and region.
- **Webhooks** – Moved signing secret clean-up to an off-peak window in each region.
- **Search** – Index writes are now retried once on a transient database error.
- **Search** – Filter validation errors now return a machine-readable `code` field.
- **Audit Log** – Stream writes are now retried once on a transient database error.
- **Audit Log** – Structured logs for stream operations now include the account ID and region.
- **Integrations** – Reduced p95 latency of sync job lookups.

## Fixed in 2026-06

- **Accounts** – Fixed incorrect counts after a account was restored.
- **Auth** – Fixed retries creating a second MFA enrolment after a gateway timeout.
- **Auth** – Fixed retries creating a second session after a gateway timeout.
- **Billing** – Fixed a server error when listing credits for an account that has none.
- **Billing** – Fixed time zone handling so invoice timestamps are always UTC.
- **Support** – Fixed a race when two requests updated the same SLA timer.
- **Webhooks** – Fixed a server error when listing events for an account that has none.
- **Integrations** – Fixed retries creating a second sync job after a gateway timeout.
