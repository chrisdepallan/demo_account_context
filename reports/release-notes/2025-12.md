# Release Notes 2025-12

## Summary

In **2025-12**, **12 services** shipped **42 changes**: **14 additions**, **9 improvements** and **19 fixes**. Each service's full history is in its `CHANGELOG.md`.

## New in 2025-12

- **Accounts** – Added bulk account export to the API.
- **Accounts** – Added pagination cursors to plan change listings.
- **Auth** – Added a dry-run mode for API key imports.
- **Auth** – Added pagination cursors to MFA enrolment listings.
- **Support** – Added a dry-run mode for ticket imports.
- **Support** – Added bulk escalation export to the API.
- **Projects** – Added pagination cursors to comment listings.
- **Projects** – Added a dry-run mode for project imports.
- **Files** – Added a dry-run mode for sharing link imports.
- **Notifications** – Added an `updated_since` filter when listing email templates.
- **Notifications** – Added a dry-run mode for email template imports.
- **Notifications** – Added pagination cursors to digest listings.
- **Webhooks** – Added per-region metrics for delivery operations.
- **Search** – Added pagination cursors to query listings.

## Improved in 2025-12

- **Auth** – Moved SSO connection clean-up to an off-peak window in each region.
- **Support** – Moved SLA timer clean-up to an off-peak window in each region.
- **Support** – Structured logs for escalation operations now include the account ID and region.
- **Notifications** – Moved notification clean-up to an off-peak window in each region.
- **Webhooks** – Moved event clean-up to an off-peak window in each region.
- **Audit Log** – Reduced p95 latency of export lookups.
- **Audit Log** – Moved stream clean-up to an off-peak window in each region.
- **Integrations** – Structured logs for sync job operations now include the account ID and region.
- **Analytics** – Reduced p95 latency of metric lookups.

## Fixed in 2025-12

- **Accounts** – Fixed a server error when listing workspaces for an account that has none.
- **Accounts** – Fixed time zone handling so member invitation timestamps are always UTC.
- **Auth** – Fixed a server error when listing SSO connections for an account that has none.
- **Billing** – Fixed a race when two requests updated the same invoice.
- **Billing** – Fixed a race when two requests updated the same refund.
- **Billing** – Fixed a race when two requests updated the same credit.
- **Billing** – Fixed a server error when listing refunds for an account that has none.
- **Projects** – Fixed retries creating a second task after a gateway timeout.
- **Files** – Fixed a race when two requests updated the same file.
- **Files** – Fixed retries creating a second sharing link after a gateway timeout.
- **Webhooks** – Fixed time zone handling so signing secret timestamps are always UTC.
- **Webhooks** – Fixed a race when two requests updated the same event.
- **Search** – Fixed time zone handling so filter timestamps are always UTC.
- **Audit Log** – Fixed export listings returning duplicates across pages.
- **Audit Log** – Fixed retries creating a second retention policy after a gateway timeout.
- **Integrations** – Fixed incorrect counts after a OAuth grant was restored.
- **Integrations** – Fixed install listings returning duplicates across pages.
- **Analytics** – Fixed metric listings returning duplicates across pages.
- **Analytics** – Fixed incorrect counts after a report was restored.
