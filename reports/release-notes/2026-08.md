# Release Notes 2026-08

## Summary

In **2026-08**, **12 services** shipped **37 changes**: **14 additions**, **10 improvements** and **13 fixes**. Each service's full history is in its `CHANGELOG.md`.

## New in 2026-08

- **Accounts** – Added an audit entry whenever a plan change is deleted.
- **Auth** – Added an `updated_since` filter when listing API keys.
- **Billing** – Added a dry-run mode for refund imports.
- **Billing** – Added an `updated_since` filter when listing subscriptions.
- **Projects** – Added an audit entry whenever a comment is deleted.
- **Files** – Added an `updated_since` filter when listing file versions.
- **Files** – Added an `updated_since` filter when listing sharing links.
- **Notifications** – Added per-region metrics for notification operations.
- **Webhooks** – Added bulk event export to the API.
- **Webhooks** – Added pagination cursors to webhook endpoint listings.
- **Search** – Added bulk query export to the API.
- **Audit Log** – Added an audit entry whenever a retention policy is deleted.
- **Integrations** – Added an audit entry whenever a sync job is deleted.
- **Integrations** – Added an `updated_since` filter when listing integrations.

## Improved in 2026-08

- **Auth** – Session writes are now retried once on a transient database error.
- **Billing** – Refund writes are now retried once on a transient database error.
- **Support** – Ticket writes are now retried once on a transient database error.
- **Support** – Structured logs for macro operations now include the account ID and region.
- **Support** – Reduced p95 latency of ticket lookups.
- **Webhooks** – Reduced p95 latency of delivery lookups.
- **Search** – Moved filter clean-up to an off-peak window in each region.
- **Search** – Structured logs for query operations now include the account ID and region.
- **Integrations** – Reduced p95 latency of OAuth grant lookups.
- **Analytics** – Scheduled export writes are now retried once on a transient database error.

## Fixed in 2026-08

- **Accounts** – Fixed a server error when listing plan changes for an account that has none.
- **Auth** – Fixed incorrect counts after a MFA enrolment was restored.
- **Billing** – Fixed incorrect counts after a credit was restored.
- **Support** – Fixed time zone handling so ticket timestamps are always UTC.
- **Projects** – Fixed time zone handling so board timestamps are always UTC.
- **Projects** – Fixed comment listings returning duplicates across pages.
- **Files** – Fixed a race when two requests updated the same file version.
- **Notifications** – Fixed time zone handling so preference timestamps are always UTC.
- **Webhooks** – Fixed event listings returning duplicates across pages.
- **Search** – Fixed query listings returning duplicates across pages.
- **Audit Log** – Fixed time zone handling so audit entry timestamps are always UTC.
- **Audit Log** – Fixed retries creating a second stream after a gateway timeout.
- **Analytics** – Fixed a race when two requests updated the same dashboard.
