# Release Notes 2025-10

## Summary

In **2025-10**, **12 services** shipped **38 changes**: **13 additions**, **11 improvements** and **14 fixes**. Each service's full history is in its `CHANGELOG.md`.

## New in 2025-10

- **Accounts** – Added bulk plan change export to the API.
- **Accounts** – Added per-region metrics for account operations.
- **Auth** – Added bulk MFA enrolment export to the API.
- **Auth** – Added an audit entry whenever a API key is deleted.
- **Billing** – Added pagination cursors to refund listings.
- **Projects** – Added bulk task export to the API.
- **Projects** – Added per-region metrics for board operations.
- **Files** – Added an audit entry whenever a file is deleted.
- **Notifications** – Added an `updated_since` filter when listing preferences.
- **Audit Log** – Added an `updated_since` filter when listing audit entries.
- **Integrations** – Added an audit entry whenever a install is deleted.
- **Analytics** – Added an audit entry whenever a dashboard is deleted.
- **Analytics** – Added a dry-run mode for scheduled export imports.

## Improved in 2025-10

- **Accounts** – Workspace writes are now retried once on a transient database error.
- **Billing** – Credit validation errors now return a machine-readable `code` field.
- **Support** – Ticket validation errors now return a machine-readable `code` field.
- **Support** – SLA timer validation errors now return a machine-readable `code` field.
- **Support** – Escalation validation errors now return a machine-readable `code` field.
- **Projects** – Task validation errors now return a machine-readable `code` field.
- **Notifications** – Moved email template clean-up to an off-peak window in each region.
- **Webhooks** – Reduced p95 latency of signing secret lookups.
- **Audit Log** – Export writes are now retried once on a transient database error.
- **Analytics** – Moved report clean-up to an off-peak window in each region.
- **Analytics** – Reduced p95 latency of report lookups.

## Fixed in 2025-10

- **Auth** – Fixed retries creating a second API key after a gateway timeout.
- **Auth** – Fixed time zone handling so MFA enrolment timestamps are always UTC.
- **Billing** – Fixed refund listings returning duplicates across pages.
- **Support** – Fixed incorrect counts after a macro was restored.
- **Projects** – Fixed incorrect counts after a task was restored.
- **Files** – Fixed a race when two requests updated the same upload.
- **Webhooks** – Fixed a race when two requests updated the same delivery.
- **Webhooks** – Fixed delivery listings returning duplicates across pages.
- **Search** – Fixed incorrect counts after a index was restored.
- **Search** – Fixed time zone handling so saved search timestamps are always UTC.
- **Search** – Fixed filter listings returning duplicates across pages.
- **Audit Log** – Fixed a race when two requests updated the same stream.
- **Audit Log** – Fixed a server error when listing retention policies for an account that has none.
- **Integrations** – Fixed a race when two requests updated the same install.
