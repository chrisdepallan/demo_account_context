# Release Notes 2026-04

## Summary

In **2026-04**, **12 services** shipped **40 changes**: **18 additions**, **12 improvements** and **10 fixes**. Each service's full history is in its `CHANGELOG.md`.

- **Accounts** – Added an `updated_since` filter when listing workspaces.
- **Accounts** – Added pagination cursors to account listings.
- **Auth** – Added bulk API key export to the API.
- **Billing** – Added an audit entry whenever a refund is deleted.
- **Support** – Added a dry-run mode for macro imports.
- **Support** – Added bulk macro export to the API.
- **Projects** – Added per-region metrics for task operations.
- **Projects** – Added a dry-run mode for comment imports.
- **Files** – Added bulk upload export to the API.
- **Notifications** – Added an audit entry whenever a digest is deleted.
- **Webhooks** – Added pagination cursors to event listings.
- **Webhooks** – Added bulk signing secret export to the API.
- **Search** – Added an audit entry whenever a index is deleted.
- **Search** – Added an audit entry whenever a query is deleted.
- **Audit Log** – Added an audit entry whenever a export is deleted.
- **Audit Log** – Added a dry-run mode for retention policy imports.
- **Integrations** – Added an `updated_since` filter when listing OAuth grants.
- **Analytics** – Added pagination cursors to dashboard listings.

## Improved in 2026-04

- **Accounts** – Moved member invitation clean-up to an off-peak window in each region.
- **Accounts** – Moved plan change clean-up to an off-peak window in each region.
- **Auth** – Reduced p95 latency of SSO connection lookups.
- **Billing** – Credit writes are now retried once on a transient database error.
- **Support** – Macro validation errors now return a machine-readable `code` field.
- **Projects** – Board writes are now retried once on a transient database error.
- **Files** – File validation errors now return a machine-readable `code` field.
- **Notifications** – Notification writes are now retried once on a transient database error.
- **Search** – Moved saved search clean-up to an off-peak window in each region.
- **Search** – Structured logs for saved search operations now include the account ID and region.
- **Audit Log** – Structured logs for retention policy operations now include the account ID and region.
- **Analytics** – Reduced p95 latency of scheduled export lookups.

## Fixed in 2026-04

- **Auth** – Fixed session listings returning duplicates across pages.
- **Auth** – Fixed a race when two requests updated the same SSO connection.
- **Support** – Fixed retries creating a second SLA timer after a gateway timeout.
- **Projects** – Fixed time zone handling so task timestamps are always UTC.
- **Webhooks** – Fixed incorrect counts after a delivery was restored.
- **Audit Log** – Fixed time zone handling so retention policy timestamps are always UTC.
- **Integrations** – Fixed a race when two requests updated the same sync job.
- **Integrations** – Fixed retries creating a second OAuth grant after a gateway timeout.
- **Integrations** – Fixed time zone handling so integration timestamps are always UTC.
- **Analytics** – Fixed incorrect counts after a scheduled export was restored.
