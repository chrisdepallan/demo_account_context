# Release Notes 2025-11

## Summary

In **2025-11**, **12 services** shipped **40 changes**: **14 additions**, **13 improvements** and **13 fixes**. Each service's full history is in its `CHANGELOG.md`.

## New in 2025-11

- **Accounts** – Added per-region metrics for member invitation operations.
- **Accounts** – Added an audit entry whenever a workspace is deleted.
- **Auth** – Added a dry-run mode for MFA enrolment imports.
- **Auth** – Added an `updated_since` filter when listing SSO connections.
- **Auth** – Added an `updated_since` filter when listing MFA enrolments.
- **Billing** – Added an audit entry whenever a credit is deleted.
- **Billing** – Added pagination cursors to invoice listings.
- **Projects** – Added per-region metrics for comment operations.
- **Projects** – Added an audit entry whenever a project is deleted.
- **Webhooks** – Added a dry-run mode for signing secret imports.
- **Webhooks** – Added per-region metrics for event operations.
- **Search** – Added pagination cursors to filter listings.
- **Audit Log** – Added pagination cursors to retention policy listings.
- **Integrations** – Added an audit entry whenever a OAuth grant is deleted.

## Improved in 2025-11

- **Accounts** – Reduced p95 latency of plan change lookups.
- **Accounts** – Plan change writes are now retried once on a transient database error.
- **Billing** – Moved subscription clean-up to an off-peak window in each region.
- **Support** – Macro writes are now retried once on a transient database error.
- **Projects** – Structured logs for board operations now include the account ID and region.
- **Files** – Upload validation errors now return a machine-readable `code` field.
- **Files** – Reduced p95 latency of file lookups.
- **Files** – Reduced p95 latency of sharing link lookups.
- **Notifications** – Structured logs for preference operations now include the account ID and region.
- **Notifications** – Reduced p95 latency of email template lookups.
- **Search** – Query validation errors now return a machine-readable `code` field.
- **Audit Log** – Stream validation errors now return a machine-readable `code` field.
- **Analytics** – Reduced p95 latency of dashboard lookups.

## Fixed in 2025-11

- **Support** – Fixed retries creating a second ticket after a gateway timeout.
- **Projects** – Fixed incorrect counts after a board was restored.
- **Notifications** – Fixed a server error when listing email templates for an account that has none.
- **Webhooks** – Fixed retries creating a second delivery after a gateway timeout.
- **Webhooks** – Fixed time zone handling so event timestamps are always UTC.
- **Search** – Fixed retries creating a second query after a gateway timeout.
- **Search** – Fixed a race when two requests updated the same filter.
- **Audit Log** – Fixed a server error when listing exports for an account that has none.
- **Audit Log** – Fixed a race when two requests updated the same export.
- **Integrations** – Fixed OAuth grant listings returning duplicates across pages.
- **Analytics** – Fixed a server error when listing metrics for an account that has none.
- **Analytics** – Fixed retries creating a second metric after a gateway timeout.
- **Analytics** – Fixed retries creating a second scheduled export after a gateway timeout.
