# Release Notes 2026-01

## Summary

In **2026-01**, **12 services** shipped **39 changes**: **6 additions**, **12 improvements** and **21 fixes**. Each service's full history is in its `CHANGELOG.md`.

## New in 2026-01

- **Accounts** – Added an `updated_since` filter when listing member invitations.
- **Billing** – Added a dry-run mode for subscription imports.
- **Projects** – Added bulk project export to the API.
- **Webhooks** – Added a dry-run mode for delivery imports.
- **Search** – Added an `updated_since` filter when listing indexes.
- **Analytics** – Added pagination cursors to scheduled export listings.

## Improved in 2026-01

- **Auth** – Structured logs for MFA enrolment operations now include the account ID and region.
- **Auth** – Reduced p95 latency of API key lookups.
- **Billing** – Subscription validation errors now return a machine-readable `code` field.
- **Support** – Reduced p95 latency of escalation lookups.
- **Files** – Upload writes are now retried once on a transient database error.
- **Files** – Moved file version clean-up to an off-peak window in each region.
- **Notifications** – Email template validation errors now return a machine-readable `code` field.
- **Webhooks** – Structured logs for signing secret operations now include the account ID and region.
- **Search** – Saved search validation errors now return a machine-readable `code` field.
- **Integrations** – Integration validation errors now return a machine-readable `code` field.
- **Integrations** – Reduced p95 latency of integration lookups.
- **Analytics** – Structured logs for metric operations now include the account ID and region.

## Fixed in 2026-01

- **Accounts** – Fixed incorrect counts after a workspace was restored.
- **Accounts** – Fixed retries creating a second account after a gateway timeout.
- **Accounts** – Fixed workspace listings returning duplicates across pages.
- **Auth** – Fixed retries creating a second SSO connection after a gateway timeout.
- **Auth** – Fixed incorrect counts after a SSO connection was restored.
- **Billing** – Fixed time zone handling so credit timestamps are always UTC.
- **Billing** – Fixed a server error when listing subscriptions for an account that has none.
- **Support** – Fixed macro listings returning duplicates across pages.
- **Support** – Fixed a race when two requests updated the same ticket.
- **Support** – Fixed incorrect counts after a escalation was restored.
- **Projects** – Fixed retries creating a second board after a gateway timeout.
- **Projects** – Fixed a server error when listing projects for an account that has none.
- **Files** – Fixed retries creating a second file after a gateway timeout.
- **Files** – Fixed time zone handling so file version timestamps are always UTC.
- **Notifications** – Fixed incorrect counts after a email template was restored.
- **Search** – Fixed incorrect counts after a query was restored.
- **Search** – Fixed incorrect counts after a filter was restored.
- **Audit Log** – Fixed a race when two requests updated the same audit entry.
- **Audit Log** – Fixed incorrect counts after a stream was restored.
- **Audit Log** – Fixed retries creating a second audit entry after a gateway timeout.
- **Analytics** – Fixed scheduled export listings returning duplicates across pages.
