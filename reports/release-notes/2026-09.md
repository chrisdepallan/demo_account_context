# Release Notes 2026-09

## Summary

In **2026-09**, **12 services** shipped **33 changes**: **17 additions**, **7 improvements** and **9 fixes**. Each service's full history is in its `CHANGELOG.md`.

## New in 2026-09

- **Accounts** – Added an audit entry whenever a member invitation is deleted.
- **Auth** – Added per-region metrics for session operations.
- **Billing** – Added per-region metrics for refund operations.
- **Billing** – Added bulk invoice export to the API.
- **Projects** – Added an `updated_since` filter when listing projects.
- **Projects** – Added bulk board export to the API.
- **Notifications** – Added an audit entry whenever a preference is deleted.
- **Notifications** – Added pagination cursors to email template listings.
- **Notifications** – Added bulk digest export to the API.
- **Search** – Added a dry-run mode for query imports.
- **Search** – Added pagination cursors to saved search listings.
- **Audit Log** – Added a dry-run mode for export imports.
- **Audit Log** – Added a dry-run mode for audit entry imports.
- **Audit Log** – Added an audit entry whenever a audit entry is deleted.
- **Integrations** – Added bulk OAuth grant export to the API.
- **Analytics** – Added a dry-run mode for metric imports.
- **Analytics** – Added per-region metrics for metric operations.

## Improved in 2026-09

- **Accounts** – Moved workspace clean-up to an off-peak window in each region.
- **Accounts** – Account writes are now retried once on a transient database error.
- **Auth** – MFA enrolment validation errors now return a machine-readable `code` field.
- **Webhooks** – Signing secret writes are now retried once on a transient database error.
- **Webhooks** – Reduced p95 latency of event lookups.
- **Search** – Moved query clean-up to an off-peak window in each region.
- **Integrations** – Integration writes are now retried once on a transient database error.

## Fixed in 2026-09

- **Accounts** – Fixed a race when two requests updated the same account.
- **Support** – Fixed retries creating a second macro after a gateway timeout.
- **Support** – Fixed time zone handling so macro timestamps are always UTC.
- **Support** – Fixed a race when two requests updated the same escalation.
- **Projects** – Fixed incorrect counts after a comment was restored.
- **Files** – Fixed a server error when listing files for an account that has none.
- **Files** – Fixed incorrect counts after a sharing link was restored.
- **Audit Log** – Fixed retries creating a second export after a gateway timeout.
- **Analytics** – Fixed retries creating a second report after a gateway timeout.
